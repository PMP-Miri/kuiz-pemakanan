# NutriArena POP 3.0

Kemas kini reka bentuk untuk pemasangan NutriArena 26 Aktiviti yang sedia ada.

1. Simpan backup.
2. Upload isi pakej ke akar repositori. Kekalkan folder `src` dan `assets`.
3. KEKALKAN `config.js` yang telah diisi. Fail tersebut tidak disertakan.
4. Tiada SQL baharu jika migrasi 26 Aktiviti sudah dipasang.
5. Buka `pratonton.html` untuk melihat semua format. Pegawai masuk melalui `pegawai.html`.

Baca **KEMAS-KINI-DESIGN-POP.md** untuk langkah penuh, had, ujian dan rollback.

320 semakan kod dalam harness terasing lulus. Beberapa paparan contoh dirender pada saiz TV dan telefon. Supabase live, audio, upload serta peranti sebenar belum diuji semula.
