# Semakan POP 3.0

320/320 semakan kod dilihat lulus dalam fixture terasing: 181 model/markup, 128 reka bentuk/privasi dan 11 sintaks modul. Lihat POP-VERIFICATION.json.

Lapan senario paparan contoh dirender dan dilihat pada saiz TV serta telefon. Fixture tidak mengakses Supabase dan menggunakan font fallback sistem. Ini bukan pengesahan semua gabungan kandungan atau peranti.

Semakan import, named export, rujukan HTML, kontras teks utama dan simulasi overlay config dijalankan semasa pembungkusan. Model pemarkahan, API, demo dan audio dibandingkan dengan versi sebelumnya; hanya parameter versi import berubah.

Belum diuji: laman yang sedang diterbitkan, Supabase live, TV fizikal, audio/perakam/seret dan upload sebenar. Jalankan percubaan selepas update sebelum acara.

Buka tests/design.html untuk 309 semakan model/reka bentuk tanpa backend. 11 semakan sintaks pembinaan direkodkan berasingan.
